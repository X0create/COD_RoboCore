# 待验证清单（上板 / 台架）

代码先写好并通过编译和主机测试，需要硬件才能确认的项目记在这里，攒起来集中上板。
**主机测试通过不等于上板通过**；本表每一项通过后，把状态改为“通过”并写日期，同时更新相关文档里的验证层级。

- 状态：**待验证**、**通过（日期）**、**失败（日期，现象）**。
- 固件：WSL 中 `cmake --build --preset h723-bench-debug`，Ozone 烧录后看 RTT（`docs/DEV_ENVIRONMENT.md` 第 10 节）。
- **涉及电机的项目一律排在最后**，并满足台架条件：电机固定在台架上、输出轴不连负载、断电开关放在手边、先确认电调超时行为。
