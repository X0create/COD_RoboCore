# 单电机速度试验

`motor_bench.h/.c`：定长梯形参考、分方向摩擦 / 惯量前馈、总输出条件积分和运行状态机；不访问外设。
`telemetry/`：本队系统辨识项目 MIT 记录协议快照，出处 / 校验值在其 README。
参数唯一位置在 `01_applic/config/motor_bench_robot.h`，任务在 `01_applic/tasks/motor_bench_*`。

前馈只在起步稳定后的运动段启用，切入 / 切出转移恒速摩擦积分份额；加速度前馈仍按规划加速度变化。
下档 / 中档 / 运行结束 / 故障均撤力矩并清积分；完成 / 故障后需要重新下→中准备。
运动参数在运行开始时冻结；撤去 `allow_motion` 立即取消运动。硬件验证和使用范围见 `docs/M3508_CONTROL_BENCH.md`。

`motor_bench_link.h/.c`：MB01 参数命令的单请求交接。通信任务提交 / 取回执，控制任务校验并应用，原子状态交接载荷所有权。
USB 接收 / 回执经过本队 sysid 插件的统一帧解析与发送，不另开 USB 发送方。拒绝参数时返回当前值，不部分修改。
运行中拒绝整组修改；撤销运动准备单独锁存，即使普通邮箱忙也优先处理。保护温度与模型温度覆盖分开，完整协议在辨识仓库 `docs/cn/firmware_module.md`。
